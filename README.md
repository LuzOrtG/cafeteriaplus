# **☕ CafeteriaPlus**

**CafeteriaPlus** es un sistema de gestión integral para cafeterías desarrollado en Python con interfaz gráfica (Tkinter). Permite administrar inventario, realizar pedidos, gestionar usuarios y generar reportes de ventas.

## 🔍 Características Principales

### 🖥️ **Interfaz de Usuario Intuitiva**
- Pantalla de bienvenida con animación
- Navegación sencilla entre módulos
- Diseño responsive para diferentes pantallas

### 🔐 **Sistema de Autenticación**
- Roles diferenciados (Administrador/Cliente)
- Registro de nuevos usuarios
- Encriptación de contraseñas
- Credenciales por defecto para primer acceso

### 📦 **Gestión de Productos**
- Catálogo organizado por categorías (Bebidas/Postres)
- Ficha completa por producto:
  - Nombre
  - Precio
  - Imagen
  - Ingredientes requeridos
- Opciones CRUD completas (Crear, Leer, Actualizar, Eliminar)

### 📊 **Control de Inventario**
- Sistema automatizado de stock
- Alertas de ingredientes bajos
- Unidades de medida inteligentes (ml, gr, unidades)
- Valores predeterminados configurables

### 🛒 **Sistema de Pedidos**
- Carrito de compras interactivo
- Cálculo automático de totales
- Validación de disponibilidad
- Generación de tickets
- Historial completo de transacciones

### 📈 **Reportes y Análisis**
- Dashboard administrativo
- Registro detallado de ventas
- Filtros por fecha/rango temporal
- Opción de reinicio controlado

### ⚙️ **Administración del Sistema**
- Gestión de usuarios
- Configuración de seguridad
- Respaldo automático de datos
- Personalización de parámetros iniciales

### 🔄 **Persistencia de Datos**
- Almacenamiento en formato JSON
- Sistema de recuperación ante fallos
- Actualización en tiempo real
- Estructura modular escalable


## ------------------------------------
## **⚙️ Requisitos del Sistema**

- Python 3.8 o superior
- Pillow (pip install pillow) para manejar imágenes
- Tkinter (incluido con Python en la mayoría de instalaciones)
- Sistema operativo: Windows (configurado para rutas absolutas tipo "D:/...")


## ------------------------------------
## **▶️ Cómo Ejecutar**
1. ✅ Asegúrate de tener Python instalado
Este proyecto requiere Python 3.10 o superior.

En Windows
Abre una terminal (cmd, PowerShell o Terminal de VS Code) y ejecuta:\
python --version
Si no está instalado, descárgalo desde: https://www.python.org/downloads/

Asegúrate de marcar la opción “Add Python to PATH” durante la instalación.

2. 📁 Descarga el proyecto
- Descarga o clona este repositorio.
- Ejecuta el archivo principal que se encuentra dentro de la carpeta DESCARGAS Y COSAS:

    **cafeteriaplus.py**

3. 🚀 Ejecuta el programa
Desde una terminal, ejecuta el script

El icono, splash y productos usan imágenes ubicadas por defecto en D:/DESCARGAS Y COSAS/, cambia esa ruta si estás en otro sistema operativo o ubicación.

Apóyate de la guía de usuario que se encuentra en este mismo repositorio, sigue las instrucciones para iniciar sesión, ver productos, hacer pedidos, etc.

## ------------------------------------
## **🖥 Cómo descargar y ejecutar el ejecutabler**
⚠️ Requisitos del sistema
- Sistema operativo: Windows 7, 10, 11

- Arquitectura: 64 bits (x64)

- No requiere instalación adicional
##
📦 Paso 1: **Descargar el ejecutable**
1. Descarga el archivo comprimido:

👉 cafeteriaplus_ejecutable.rar

2. Extrae el contenido usando un programa como WinRAR, 7-Zip o Windows Explorer.

##

💡 Paso 2: **Ejecutar el programa**

1. Dentro de la carpeta extraída, busca el archivo **cafeteriaplus.exe** que se encuentra en la carpeta llamada dist.

2. Haz doble clic sobre él para abrir el programa o tambien puedes arrastrar el archivo al escritorio para mas comodidad y posteriormente darle doble clic.

3. El sistema se abrirá en una ventana de consola (terminal).

Apóyate de la guía de usuario que se encuentra en este mismo repositorio, sigue las instrucciones para iniciar sesión, ver productos, hacer pedidos, etc.
